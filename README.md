# Basketball Shooter Installation

This repo has the code and CAD files for a basketball shooter art installation at Lonsdale Quay.

Access2Innovate runs STEM and STEAM programs, camps, and workshops for students. This project was built as one of our hands-on public installations.

## What’s in here

* Controller source code
* CAD files for some of the parts
